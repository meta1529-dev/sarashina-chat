# Sarashina Chat

## これは何か

Sarashina APIに自分のAPIキーで接続する、依存パッケージ不要のチャットクライアントです。非公式ツールであり、SB Intuitionsとは無関係です。画面・サーバーとも外部ライブラリやCDNを使用しません。Node.js 18以上が必要です。

## 対応モデル表

| モデル | コンテキスト | 用途 | 思考レベル |
| --- | --- | --- | --- |
| sarashina3.2-mini-thinking | 128k | 思考型チャット（既定） | 浅め・標準・深め |
| sarashina3-mini | 128k | 標準チャット | 非対応 |
| sarashina3-nano | 128k | 軽量・高速チャット | 非対応 |
| sarashina3-guard | 64k | 安全性判定専用 | 非対応 |

判定モデルは文章を生成せず、「安全」や「有害」とカテゴリコードを返します。入力した今回のテキストのみを送信します。履歴がある状態でモデルを変更すると、確認後に会話をリセットします。

思考型モデルの暗号化されたreasoningデータは表示せず、受信した文字列を変更せずに次の会話へ引き継ぎます。停止・通信切断などで未完了となったターンは履歴に追加しません。会話履歴とシステムプロンプトはメモリ内のみで、再読み込みで消えます。

## APIキーの取得方法

[公式ダッシュボード](https://chat.sarashina.ai/dashboard/api-keys)でAPIキーを発行し、画面の「設定」にあるAPIキー欄に貼り付けてください。

## 使い方A: ローカルで使う

```sh
node server.mjs
```

http://127.0.0.1:8787 を開き、「APIキーを設定」からキーを貼り付けます。貼り付け後に接続テストが自動で一度実行されます。接続方式は既定の「自動」でローカルプロキシを使用します。上部でモデルを選び、下部の入力欄から送信してください。思考型モデルでは「浅め／標準／深め」を選べます。Enterで送信、Shift+Enterで改行、生成中の「■ 停止」またはEscで中断します。ポートは環境変数PORTで変更できます。サーバーは127.0.0.1のみにバインドします。

「設定」では接続方式、システムプロンプト、温度、最大出力トークン数、ストリーミングを変更できます。「接続テスト」は手動でも実行できます。例文ボタンは入力欄への挿入のみです。応答やコードのコピー、最後の応答の再生成、未完了応答の再試行に対応します。「新しい会話」で会話をリセットします。

プロキシは `/api/chat/completions` と `/api/models` のみを公式APIへ転送します。APIキーをログへ出力しません。

## 使い方B: GitHub Pages等の静的ホスティング

index.html、style.css、sse.js、app.jsを同じディレクトリに配置して公開できます。ビルドは不要です。Pages版は既定の「自動」でデモ案内を表示し、キーの入力を促しません。実利用は使い方Aのローカルプロキシで行ってください。「設定」で「ブラウザから直接」を明示的に選ぶと直接接続を試せます。

静的ホスティングからの直接接続は、2026-10-29にGitHub Pages上の実ページで接続テストを行い、CORSでブロックされることを確認しました（ネットワークエラーになります）。そのため、実際にチャットするには使い方Aのローカルプロキシが推奨経路です。Pages版は画面の確認・デモ用とお考えください。接続方式「自動」はlocalhost・127.0.0.1ではプロキシ、それ以外では直接接続に解決されます。以前保存した接続方式は引き継ぎます。

## セキュリティ注意

- 公式はクライアントサイドでのAPIキー利用を推奨していません。このツールは個人利用に限って使用してください。
- キーは選択した接続先（公式Sarashina API、またはこのページの同一オリジンのローカルプロキシ）以外へ送信しません。プロキシからは公式APIへ転送します。信頼できるページ・サーバーで使用してください。
- キーの保存は既定でsessionStorageによるセッションのみです。「この端末に保存する」を選んだ場合だけlocalStorageへ保存します。チェックを外すと永続保存分を削除します。保存できない環境ではメモリ内のみで使用します。
- 共用PCではキーを保存しないでください。利用後は「削除」で入力欄と両方の保存先からキーを消し、タブを閉じてください。
- 利用上限を設定したキーを推奨します。漏えいした場合はすぐ無効化してください。
- github.io配下では、同一オリジン（同じホスト）の別サイト・別リポジトリのページからlocalStorageを読めます。パスでは保存領域を分離できません。sessionStorageも同一オリジンのスクリプトからアクセス可能です。
- 送信した本文・会話履歴・システムプロンプトはSarashina APIで処理されます。

## file:// では動きません

index.htmlをファイルとして直接開く方法は非対応です。ローカルサーバーまたはHTTP/HTTPSの静的ホスティングを使用してください。

## 開発

外部依存のインストールは不要です。

```sh
npm test
node --check app.js
node --check sse.js
node --check server.mjs
```

SSEパーサーはブラウザとCommonJSの両方で利用できます。日本語・UTF-8バイト境界、分割受信、CRLF、複数data行、完了通知をテストします。実APIとの疎通には利用者のキーが必要です。
