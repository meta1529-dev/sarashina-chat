# Sarashina Chat

## これは何か

Sarashina APIに自分のAPIキーで接続する、依存パッケージ不要のチャットクライアントです。非公式ツールであり、SB Intuitionsとは無関係です。画面・サーバーとも外部ライブラリやCDNを使用しません。Node.js 18以上が必要です。

## 対応モデル表

| モデル | コンテキスト | 用途 | 思考レベル |
| --- | --- | --- | --- |
| sarashina3.2-mini-thinking | 128k | 思考型チャット（既定） | 低・中・高 |
| sarashina3-mini | 128k | 標準チャット | 非対応 |
| sarashina3-nano | 128k | 軽量・高速チャット | 非対応 |
| sarashina3-guard | 64k | 安全性判定専用 | 非対応 |

判定モデルは文章を生成せず、「安全」や「有害」とカテゴリコードを返します。入力した今回のテキストのみを送信します。モデル変更時は会話履歴をリセットします。

思考型モデルの暗号化されたreasoningデータは表示せず、受信した文字列を変更せずに次の会話へ引き継ぎます。停止・通信切断などで未完了となったターンは履歴に追加しません。会話履歴とシステムプロンプトはメモリ内のみで、再読み込みで消えます。

## APIキーの取得方法

[公式ダッシュボード](https://chat.sarashina.ai/dashboard/api-keys)でAPIキーを発行し、画面のAPIキー欄に入力してください。

## 使い方A: ローカルで使う

```sh
node server.mjs
```

http://127.0.0.1:8787 を開き、接続方式「ローカルプロキシ」を選択します。APIキーを入力して「接続テスト」で確認後、メッセージを送信します。Enterで送信、Shift+Enterで改行、生成中の「停止」で中断します。ポートは環境変数PORTで変更できます。サーバーは127.0.0.1のみにバインドします。

プロキシは `/api/chat/completions` と `/api/models` のみを公式APIへ転送します。APIキーをログへ出力しません。

## 使い方B: GitHub Pages等の静的ホスティング

index.html、style.css、sse.js、app.jsを同じディレクトリに配置して公開し、接続方式「ブラウザから直接」を選択してください。ビルドは不要です。

静的ホスティングからの直接接続は未検証です。ブラウザからapi.sarashina.aiへの直接接続がCORSで許可されない場合は動作しません。その場合は使い方Aのローカルプロキシを利用してください。接続方式はlocalhost・127.0.0.1ではプロキシ、それ以外では直接接続が初期値です。

## セキュリティ注意

- 公式はクライアントサイドでのAPIキー利用を推奨していません。このツールは個人利用に限って使用してください。
- キーは選択した接続先（公式Sarashina API、またはこのページの同一オリジンのローカルプロキシ）以外へ送信しません。プロキシからは公式APIへ転送します。信頼できるページ・サーバーで使用してください。
- キーの保存は既定でsessionStorageによるセッションのみです。「キーを保存する」を選んだ場合だけlocalStorageへ保存します。チェックを外すと永続保存分を削除します。保存できない環境ではメモリ内のみで使用します。
- 共用PCではキーを保存しないでください。利用後はキー欄を空にしてタブを閉じてください。
- 利用上限を設定したキーを推奨します。漏えいした場合はすぐ無効化してください。
- github.io配下では、同一オリジン（同じホスト）の別サイト・別リポジトリのページからlocalStorageを読めます。パスでは保存領域を分離できません。sessionStorageも同一オリジンのスクリプトからアクセス可能です。
- 送信した本文・会話履歴・システムプロンプトはSarashina APIで処理されます。

## file:// では動きません

index.htmlをファイルとして直接開く方法は非対応です。ローカルサーバーまたはHTTP/HTTPSの静的ホスティングを使用してください。

## 開発

外部依存のインストールは不要です。

```sh
npm test
node --check app.js
node --check sse.js
node --check server.mjs
```

SSEパーサーはブラウザとCommonJSの両方で利用できます。日本語・UTF-8バイト境界、分割受信、CRLF、複数data行、完了通知をテストします。実APIとの疎通には利用者のキーが必要です。
